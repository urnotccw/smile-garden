## 三项交付

- Live Demo：恢复发布后，部署最新 dist 到 HTTPS；用未登录的另一台设备验证完整访问、模型与素材无 404、允许摄像头后实际可玩。本机 127.0.0.1 地址不能作为公网交卷链接。
- Public 源码：恢复发布后再配置公开仓库与推送。应包含运行说明、规则测试、便携浏览器测试、第三方许可及生成素材提示词；不要提交测试人物照片、test-results、个人路径、凭据。线上 Demo 与源码保持同一版本。
- 复盘：复制复盘.md 中不超过 200 字的正文。Prompt 来自真实对话，不能把模拟测试写成手机实测；验收完成后再更新测试范围。

## 建议的真实演示顺序（约 40–50 秒）

1. 开启镜头，展示授权和识别就绪。正常讲话时画面保持安静。
2. 微笑，看到雨滴、涟漪和由低到高的花草；手轻拨花草。
3. 张嘴大笑，雨景退出；烟花在头顶成形，散开后落到头顶变成反弹爱心。
4. 手掌接住爱心或雨滴；星星落水，涟漪出现。动作慢一些，让接触点容易看清。
5. 回到微笑，烟花约 60% 主体飞行完成后接雨。最后切换电脑横屏或纯净画面。

录像用于解释交互，不替代在线真实识别。测试视频若由图片模拟生成，必须标明模拟；不应作为真人演示提交。

## 交卷前最后检查

- 运行 npm test、npm run test:browser、npm run build。
- 按真机验收表填写 PC / iPhone / Android 与 3–5 位体验者的结果。
- 检查缩放、横竖屏、关闭重开、拒绝再允许、后台返回、相机占用。
- 记录模型冷启动、实际传输、连续 10 分钟发热与帧时间。浏览器测试的网络拦截可能禁用 HTTP 缓存，其资源统计不能替代公网冷／热缓存测试。
- 审美终检以真实摄像背景为准：人物清楚、评论能读、烟花图案可辨、碰撞方向合理、退出不留残影。
