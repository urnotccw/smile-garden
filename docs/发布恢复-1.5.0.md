# 发布恢复 · 1.5.0

2026-09-14，修复最终评估审查中可复现的线上使用问题。

- 素材管理保留稳定的图片对象和就绪通知。单次恢复周期最多请求三次，失败后没有后台轮询；在线事件或用户重试开启新周期，仅请求失败项。12 秒未完成的图片请求超时，旧回调不能覆盖新状态。花草、雨滴、爱心、星星共用该恢复策略，已加载素材不会重新处理。
- 视频播放、帧是否前进、模型就绪和人脸存在分别判断。暂停、轨道 mute 或超过 1.4 秒不前进会撤销旧交互位置；先尝试恢复播放，自动播放失败后提供手动重开入口。播放请求有超时，不无限请求相机权限；用户主动关闭后不会因页面可见而自动重开。
- 手机预览内显示必要的加载或恢复状态，正常识别后消退，不要求滚动到控制区找错误；没有添加微信换浏览器提示。状态未变化时不重复写入 DOM。
- handReady 仅表示手势模型成功就绪；失败记为 handFailed。首个有效手掌仍单独记录 firstHand。
- 锁定 Playwright 依赖；GitHub Actions 在规则测试后运行恢复、图层、表情时序和启动回退检查，成功后才构建发布。
- 更新当前交付与验证说明，旧阶段记录明确归档；复盘保留真实 Prompt，避免易过时的测试数量。

本地通过 104 项规则测试、现有布局/权限/模型启动回归、新增发布恢复回归、图层与表情回归、下载超时和主线程回退检查。检查手机故障截图，提示与操作按钮位于预览首屏，合成视频停帧不会再被显示为让用户靠近镜头。

浏览器测试使用合成视频和受控故障，不是微信或手机硬件测试。真机验收表新增微信内置浏览器和提交 SHA 字段，真实设备、多位体验者、长时间发热与正式 PDF 仍待独立完成。
